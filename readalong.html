AI 輔助朗讀評分器

錄製您的朗讀音檔，利用 Gemini API 獲得即時語音評分與回饋。

💡 如何使用本工具 (請遵循以下 4 個步驟):

  1. 步驟 1: 取得 API Key 並貼入

    請從 aistudio.google.com 取得您的 **Gemini API Key**，並貼入上方的「設定」欄位中。

  2. 步驟 2: 輸入文稿

    將您打算朗讀的**英文文稿**貼入第一個文字框。您可以使用右側的下拉選單調整字體大小。

  3. 步驟 3: 錄製語音

    點擊 **開始錄音** 按鈕。瀏覽器可能會要求麥克風權限，請務必允許。

  4. 步驟 4: 停止並等待報告

    朗讀完畢後，點擊 **停止錄音並評分**。AI 會在 10-30 秒內返回評分結果、中文回饋，以及彩色標註的轉錄稿。
